# kindmind

KindMind merupakan platform digital yang dikembangkan untuk mendukung deteksi dini dan proses pembelajaran anak dengan Autism Spectrum Disorder (ASD). Platform ini terdiri atas website untuk skrining awal berbasis eye-tracking serta aplikasi mobile yang menyediakan pembelajaran berbasis Applied Behavior Analysis (ABA), alat komunikasi AAC, pelacakan fokus, dan laporan perkembangan anak bagi orang tua maupun pendidik.
